# AI Content Studio — Project Overview

## 1. Product Vision
AI Content Studio is a standalone AI-powered content workspace for creating professional blogs, case studies, SEO metadata, research-backed drafts, and featured images.

It is independent from the existing Neno Technology website. The platform should work as a separate product and later support multiple brands, clients, and publishing destinations.

## 2. Primary Goal
Reduce the manual effort required to research, plan, write, optimize, review, and package professional content.

## 3. Initial Content Types
- Blog articles
- Case studies

## 4. Core Workflow
Topic/Input → Research → Outline → Writing → SEO → Image → Quality Check → Human Review → Export/Publish

## 5. Key Principle
AI generates and prepares content; a human remains in control of final approval and publishing.

## 6. MVP Success Criteria
- User can create a blog from a topic.
- User can create a case study from structured inputs.
- Generated content is editable.
- SEO metadata is generated.
- Research sources can be retained with the draft.
- Featured-image prompts/images can be generated.
- Content can be saved as Draft/Review/Approved.
- Content can be exported as Markdown, HTML, and JSON.
