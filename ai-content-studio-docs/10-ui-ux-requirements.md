# AI Content Studio — UI/UX Requirements

## Visual Direction
The product should feel like a modern AI workspace rather than a traditional CMS.

Suggested characteristics:
- Clean editorial interface
- Spacious layout
- Strong typography
- Minimal visual noise
- Clear generation states
- Professional dashboard
- Responsive design

## Main Navigation
- Dashboard
- Create
- Content
- Research
- Media
- Templates
- Settings

## Dashboard
Show:
- Recent content
- Draft count
- In-review count
- Generation activity
- Quick-create actions

## Create Screen
Two primary cards:
- New Blog
- New Case Study

## Generation Workspace
Three-panel concept:
- Left: inputs/settings
- Center: generated content/editor
- Right: research, SEO, QA, and generation status

## Content Status
Use clear states:
- Draft
- Generating
- In Review
- Approved
- Exported

## UX Rules
- Autosave edits.
- Show generation progress.
- Allow regeneration by section.
- Preserve previous versions.
- Clearly distinguish AI-generated content from user edits.
- Never hide destructive actions behind ambiguous controls.
